# Colours

The ANU colour system is built on a small, purposeful palette. Consistent use of these colours helps reinforce the ANU brand, ensures accessible contrast ratios, and creates a coherent visual experience across all ANU web properties.

> **Important:** Only colours listed in the [ANU Brand Identity](https://webpublishing.anu.edu.au/web-style-guide/colours) are permitted. Do not introduce new colours. Always check contrast ratios before using any colour combination in text — refer to the [Accessibility](https://webpublishing.anu.edu.au/web-style-guide/accessibility) section for approved combinations.

## **Accessibility guidance**

The ANU Web Style Guide requires all colour combinations used for text to meet **WCAG 2.1 AA** contrast ratios (4.5:1 for normal text, 3:1 for large text).

<Markdown>
{`
| Colour use | Permitted | Notes |
| --- | --- | --- |
| Gold text on white | ❌ No | Fails AA contrast |
| White text on Gold | ✅ Yes | Passes AA at large sizes |
| White text on Black | ✅ Yes | Passes AAA |
| Black text on Tint | ✅ Yes | Passes AA |
| Link Blue on white | ✅ Yes | Passes AA |
| Gold Link (#945f00) on white | ✅ Yes | Passes AA for small text |
`}
</Markdown>

Refer to the [ANU Accessibility guidelines](https://webpublishing.anu.edu.au/web-style-guide/accessibility) for the full approved colour combination matrix.
