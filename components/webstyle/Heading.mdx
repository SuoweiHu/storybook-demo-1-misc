# Headings

Headings provide page structure, improve scannability, and signal hierarchy to both users and search engines. The ANU web style system uses **Public Sans** for all heading levels with a consistent letter-spacing and a fluid font-scale across breakpoints.

> **Important:** Only the heading styles documented here are permitted. Do not introduce custom font sizes or weights. Always verify colour combinations against the [Accessibility](https://webpublishing.anu.edu.au/web-style-guide/accessibility) guidelines.

---

## Capitalisation

Headings should use **sentence case** — only the first letter and any proper nouns are capitalised.

<Markdown>
{`
| ✅ Correct | ❌ Incorrect |
|---|---|
| Research and innovation at ANU | Research And Innovation At ANU |
| College of Engineering, Computing and Cybernetics | College Of Engineering, Computing And Cybernetics |
`}
</Markdown>
---

## Tags & hierarchy

Heading tags must be applied in a strict hierarchy. **Do not skip levels for appearance** — use the [style override classes](#style-override-classes-h1h4) instead.

```
h1  →  Page title (one per page only)
  h2  →  Section
    h3  →  Subsection
      h4  →  Sub-subsection
        h5  →  Minor heading
          h6  →  Smallest heading
```

> **Rule:** Each page must contain **exactly one `<h1>`**. Sections should use `<h2>`, subsections `<h3>`, and so on.

## Hiding headings

When a visible heading is not desirable but page structure still needs to be communicated to assistive technologies (e.g. screen readers), use the `scrnhide` class.

```html
<h2 class="scrnhide">Invisible heading</h2>
```

The heading will be hidden visually but will remain in the accessibility tree for screen reader users.

---

## Linked headings

By default, a heading containing a link will display a `»` suffix and an underline on hover. Use the `nounderline` class to suppress the underline if required by the design context.

```html
<!-- Standard linked heading -->
<h3><a href="/some-page">Example linked heading »</a></h3>

<!-- Linked heading without underline -->
<h3 class="nounderline"><a href="/some-page">Example linked heading »</a></h3>
```

View the [Links](https://webpublishing.anu.edu.au/web-style-guide/links) section for all approved linked heading styles.

## Page header (`#page-header`)

The `page-header` ID is a **special, single-use** heading style intended for the name of a school or unit that doesn't appear in the banner, or for chapter/sub-headings at the very top of a page. It may only be used **once per page**.

```html
<div id="page-header">College of Engineering, Computing and Cybernetics</div>
```

- Place the element **directly above the first content item** on the page.
- On a homepage with a banner or feature bar, the page header may sit below it — but this exception applies to the homepage only.
- Links inside the page header are styled as plain text with an underline on hover.

## SEO guidance

Heading tags signal content importance to search engines. Misusing them (e.g. using `<h1>` decoratively) damages SEO and accessibility.

> **Rule:** Each page should have **exactly one `<h1>`**, and contain a range of `<h1>` to `<h3>` heading tags at minimum.

<Markdown>
{`
| Guideline | Detail |
|---|---|
| One \`<h1>\` per page | The \`<h1>\` is the primary keyword signal to search engines. Multiple \`<h1>\`s dilute its effectiveness. |
| Use \`<h1>\`–\`<h3>\` minimum | Every page should use at least three heading levels to signal topic structure. |
| Don't skip levels | Jumping from \`<h1>\` to \`<h3>\` confuses both assistive tech and crawlers. |
| Use style overrides for visual hierarchy | Apply \`.h1\`–\`.h4\` classes instead of changing the tag when visual and semantic levels differ. |
`}
</Markdown>

## Accessibility guidance

<Markdown>
{`
| Rule | Rationale |
|---|---|
| One \`<h1>\` per page | Multiple \`<h1>\`s confuse screen readers and break ARIA landmark conventions. |
| Never skip heading levels | Screen reader users navigate by heading level — skipping creates gaps in the document outline. |
| Use \`scrnhide\` for invisible headings | Hiding with \`display: none\` removes headings from the accessibility tree entirely. |
| Gold text requires large font | \`.text-gold\` (#be830e) only passes WCAG 2.1 AA at ≥ 19px semibold or ≥ 24px regular. Never use it at body-text sizes. |
| White text needs dark background | \`.text-white\` only passes AA on \`#000000\` (black) and very dark ANU brand backgrounds. |
`}
</Markdown>

Refer to the [ANU Accessibility guidelines](https://webpublishing.anu.edu.au/web-style-guide/accessibility) for the full approved colour/background matrix.
