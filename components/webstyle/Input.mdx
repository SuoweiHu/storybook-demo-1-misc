Forms are used to collect user input. The ANU Web Style Guide provides three form themes, each offering consistent, accessible styling for input fields.

<p className="msg-warn"><strong>Please note:</strong> Form styling is applied via classes on the `<form>` tag and requires `<fieldset>` elements. You must also add the `text` class to text inputs.</p>
<br/>




## **Form themes**

Three form themes are available. Apply the class directly to your `<form>` tag:

- `anuform` — default style (light background, outlined fieldsets)
- `anuform-inline-tint` — tinted/light-grey inline style
- `anuform-inline-black` — dark/black inline style

## **Fieldsets**

Fieldsets divide a form into logical sections. Each `<fieldset>` can have an optional `<legend>` that acts as a section heading — the form styling automatically matches it to the heading colours on the rest of your site.

```html
<fieldset>
  <legend>First heading</legend>
  <!-- inputs … -->
</fieldset>
```

## **Labels**

Each input field should have a `<label>` bound to it via matching `for` / `id` attributes. This improves screen-reader accessibility and usability (clicking the label focuses the input).

The default label width is **20%** of the form area on larger screens and **100%** on smaller screens. You can widen labels by appending a class to the `<form>` tag:

- `labelwide` — 40% label width on larger screens
- `labelfull` — 100% label width on larger screens

## **Required fields**

For mandatory fields, use **both** of the following together:

- Add `class="req"` to the `<label>` — renders a red asterisk (falls back to "(required)" when JavaScript is off).
- Add `required` and `aria-required="true"` to the `<input>` — enforces HTML5 validation and provides assistive-technology support.
